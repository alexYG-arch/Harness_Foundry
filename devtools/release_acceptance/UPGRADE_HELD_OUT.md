# 升级评测保留任务（未运行）

2026-10-10：本文件与 `tests/` 开发回归分离，不纳入发行组装清单，不自动提供给目标
模型或 source gate。未用于本轮实现调参；设计者接触过场景，因此不能称为独立盲测。
具体数据与外部检查在被测源码固定后确定，由评测宿主保管；不可向模型泄漏标准答案。

- **HOLD-LEDGER**：混合有效/无效记录生成分类汇总，原始记录和用户笔记必须保留；
  一次已落盘但观察缺失的中断。独立核对全部计数、保留内容及不重复提交。
- **HOLD-CONFIG**：既有本地配置工具增加导出，保留未知配置字段；建设阶段不要求后续
  集成产物，最终调用实际消费当前被接受的导出版本。独立核对公开义务和输入版本。

各组各任务计划 3 次独立会话，最多 3 个实施 attempt/任务、30 分钟/次。上述只是待批准
评测上限，不授予模型、网络、工具、目录或运行权限。优先 A/C（原/新版 Foundry，相同
原文档）配对筛查，需要归因时再补原/澄清文档的 B/D。每组使用独立工作副本和新会话。
原业务义务、checker、模型/客户端/可知服务版本、工具、权限和预算固定。

主指标：独立业务通过率。辅指标：首轮率、修复次数、人工干预、elapsed、token/费用、
不合约效果次数。通过率不降并且预定成本指标改善，或同预算通过率提高，才可报告该样本
内的收益。两任务三重复不足以推广稳定收益；保留不确定性，不把未知成本当零。

每个真实 run 记录 task_id/run_id、foundry/document 分组、条件、PASS/FAIL/BLOCKED、
证据引用及可知指标，由 `quality_report.factorial_summary` 形成描述性报告。另保留首轮/
后续完整评测、失败和环境阻断，不只交最好一次。当前全部 NOT_RUN、收益未证实。
