# <target-name> Charter Start Package v0.1

## 定位

本目录用于启动 `<target-name>` Agent/Harness 的受控工程 Coding。它包含宪章、来源基线、阶段状态机、三工程控制面、首批 Workpack、Conformance Interface 和验收计划。

它不是：

- 已实现的 Agent/Harness；
- 已安装 Runtime；
- Linkage PASS；
- Conformance Certificate；
- Release-ready Artifact。

## 使用顺序

1. 审阅 `START.md`、`PROGRAM_CHARTER.md` 和 canonical source set。
2. 解决 `AUTHORING_HANDOFF.md` 中的 blocking decisions。
3. 批准 Profile 与 Charter Lock Candidate。
4. 运行 Start Package Validator；不得运行生成的 Workpack。
5. 以 `REGISTRATION_ONLY` 注册，不执行 Workpack。
6. 签发有界 `EXECUTION_AUTHORIZATION`，再由专用 Program Driver 推进唯一合法节点。
7. Driver 遇到硬停点后等待新的决定或授权；真实目标安装始终单独授权。
