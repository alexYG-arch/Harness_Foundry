# Main Build Project Start Package Template

本目录为 Main Harness 构建工程的独立启动包模板。它拥有自己的 Charter、状态、Workpack 与命令清单；External Lab 和 Linkage Review 不属于本工程内部阶段。

- [Project Charter](PROJECT_CHARTER.template.md)
- [Project State](PROJECT_STATE.template.json)
- [Workpack Index](WORKPACK_INDEX.template.json)
- [Command Manifest](COMMAND_MANIFEST.template.json)
- [Build and Install Plan](BUILD_INSTALL_PLAN.template.md)

默认仅生成候选计划，`auto_advance_enabled=false`。构建产物不等于认证产物，真实目标安装必须引用单独的 Real Target Install Authorization。
