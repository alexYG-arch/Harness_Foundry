# Foundry 正式发布双案例搭建文档 v0.1

状态：**DRAFT_AWAITING_HUMAN_REVIEW**。本文是进入 Foundry 前的搭建文档，不是批准，
没有创建 Program、目标目录、模型调用或运行范围。确认本文只确认业务与验收范围；
具体目录、工具、模型、有限预算和有效期仍须随后完整展示并取得运行批准。

## 目标与依据

验收对象是同一份通用 Foundry 发行归档是否能被其他操作者在自己的 Codex 中接入，
搭建符合需求、可开发使用并能独立校验/修复/恢复的 Coding Harness。
不再搭建视频专项，不把历史 M1 当作同包正式验收，不以生成文件或模型自报替代结果。

依据：[通用更新计划](FOUNDRY_GENERIC_CODEX_HARNESS_UPDATE_PLAN_v0_2.md) §8–§9，
[发布说明](RELEASE_READINESS.md)，以及下列本轮公开合成需求全文：

- 新建工程：[Task CLI 完整 PRD v0.1](../examples/task-cli/PRD.md)，映射 A1–A6。
- 既有工程：[CSV 增量项目说明 v0.1](../examples/csv-increment/PROJECT_BRIEF.md)，映射 B1–B5，
  包括同目录 starter 全部代码、原测试及模拟用户笔记。

本文与上述两份完整材料共同组成确认版本；材料变化须展示差异并重新确认受影响内容。
这是两个小而完整的验收范围，不是承诺支持所有 PRD、所有系统或任意故障。

## 交付与职责

每例交付可由 Codex 加载的项目级 Harness：工程指令、需求/开发合同、任务/产物关系、
本地检查与使用入口、失败/恢复说明，以及在该 Harness 下实际开发的完整目标程序和测试。
不得只产出 AGENTS.md、空壳脚手架或一份通过声明。

Codex/Astra 负责理解、架构、实施、调试及范围内修复，可自主选择内部结构；Foundry 控制
范围、依赖、过程观测和验收提交。确定性练习/验证使用本地 Python，不需要额外模型或云服务。
检查器从已公开业务合同建立，在目标写域外；其异常不能包装为业务断言失败。

## 建设与实际使用流程

1. 准备同一版本的、无私有状态/旧专项的 Foundry 归档与公开材料，验证新位置加载。
2. 文档确认后，从该归档准备每例的完整 Requirement/Plan、Case 合同、独立检查及具体范围。
   Review/审批记录来自真实后续消息，示例中的文字或 JSON 不算批准。
3. 新 Codex 会话从公开材料建设 Harness；后继 Codex 会话按生成的 Harness 开发程序。
   至少两个真实依赖 Workpack 自动接续，不逐包人工批准。
4. 本地运行真实 CLI 场景，读取完整 JSON、退出码、持久化数据或 CSV 结果；逐 Case 判定。
   需要写临时测试数据的练习通过独立受控 LOCAL 阶段实施，写域单独声明；
   只读验证进程不被偷偷赋予写权限，业务代码不能改独立检查器或控制状态。
5. 完成一个明确缺陷的拒绝→修复→复验→后继，以及完成观测后的恢复不重放。
   使用合成故障夹具，记录注入与撤除；不改产品验收标准，不对真实用户数据注入故障。
6. 用相同归档完成另一例；新会话仅使用发行包、材料和合法 Codex 登录，不读 Foundry
   开发目录、原私有聊天或运行库。复用操作者合法账号，不复制认证文件，不要求新账号。
7. 记录实际支持环境、每例/每 Case 结果、剩余问题和精确发行物。Foundry 若发生修复，
   重建新包并重验受影响部分；最终双案例必须绑定同一份实际交付物。

## 关键输入输出与依赖

| 阶段 | 输入 | 输出/独立判定 | 失败返回 |
|---|---|---|---|
| Harness 建设 | 已确认文档、完整 PRD/项目与发行物 | 可加载 Harness 和可执行检查入口 | 需求缺口回上游；实现错误范围内修复 |
| 实际开发 | 已验 Harness、开发需求、既有代码 | Task CLI 或 CSV audit，保留既有功能 | 业务失败重试；验收合同矛盾停止对齐 |
| 本地场景 | 被验程序、公开合成输入、必要写域 | 命令真实输出、数据文件、独立检查结果 | 环境/验证器崩溃停止，不让模型猜测 |
| 修复/恢复 | 当前控制事件和耐久观测 | 原预算内复验与继续，已完实施不重复 | 未知效果、撤销、到期或预算耗尽停止 |
| 接入与交付 | 同一归档、公开文档、新 Codex 会话 | 不依赖作者工程的构建与使用证据 | 补齐发行物并复验，不能临场打补丁冒充旧包 |

## 权限与非目标

所有代码和数据为公开合成材料。只在随后批准的独立临时工程根内写入；原 starter、
来源文档、验证代码、发行物和控制库不在目标写域。允许的读取/执行器/服务均需实际绑定。
模型服务会接收这些材料，不能把“本地文件”表述为完全不出机；本地业务步骤不联网。
总尝试、逐任务尝试、单命令时间和到期为硬限制；不声称可强制模型 token/费用上限。

本轮不覆盖真实工程、不读私有 PRD、不装全局 Skill、不改 Codex 设置、不发布应用、
不推送 GitHub、不打 tag、不上传 Release。不启用额外安全扫描或全套攻防矩阵。
Hash 仅用于最终归档 H1 与必要验收对象 H2，不增加逐消息/日志/回执摘要。
