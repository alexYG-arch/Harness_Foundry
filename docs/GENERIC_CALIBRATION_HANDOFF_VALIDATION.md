# 合同校准、可靠交回与 Case 依赖：实现及验证摘要

2026-11-02。基线为 `14b6baa3b12bbf971497d4da6ce324595833f3f3`，协议2.9。本批纳入1.3.0发行；本文是可随源码维护的摘要，本机运行证据、数据库、实际批准和 Readback 不随本文上传。

## 实现与使用入口

| 类型 | 变化与维护入口 | 兼容边界 |
| --- | --- | --- |
| 新增可选能力 | `verification_resources.case_checker_files`；见 [Build CLI](GENERIC_BUILD_CLI.md#scope) | 每个 Case 使用命令引用、全局依赖和专属依赖的并集；不猜测动态导入。省略字段保留旧模式，接受仍按 Workpack，不新增 Case 接受缓存 |
| 新增可选资料 | [RSI 校准示例](../examples/rsi-calibration/README.md)，复用现有 Wiki 查询、记录和交付工具 | 条目仍为 CANDIDATE；缺少、不适用或不采用不阻断普通任务，不自动部署或强制查询 |
| 判定与交回修正 | [合同校准](ACCEPTANCE_CONTRACT_ALIGNMENT.md)、[运行指南](GENERIC_BUILD_RUNTIME.md)及随包 Skill | 按公开合同核对字段形态和样本前提；故意无效输入仍检查真实拒错。规范 blocker 和普通自然语言疑点分别处理；不把任意措辞变成新的停止协议 |
| 依赖与复验修正 | 准备、派发、重绑定、同范围纠正和恢复使用同一 Case 文件视图与签名 | 同一 Case 可在不同 Workpack 使用不同入口。专属依赖变化只影响相关任务，共享依赖变化影响所有依赖者及原后继；首次从旧粗绑定切换仍须必要复验 |
| 交付修正 | 打包及 RSI 交付清单补入公开校准资料和所需源码依赖 | 不依赖本机测试目录；不携带私有检查预期、真实批准或控制库 |

完成生产且具备原资格时，检查器等义纠正沿现有只复验入口处理；仅该轮免扣生产额度，检查消耗仍保留。普通重绑定和历史复验保持原计数。实施阶段合同疑点不能直接包装成只复验；真实范围变更仍沿原批准流程。完整捕获只取回，不重放业务或模型。

本批未新增控制器、通用预算规则或审批层，没有把业务项目专属字段纳入公共合同，也不扩大 G1/G2。

## 工程验证

使用项目绑定的 `.venv`。按唯一测试身份归并为 **2606 PASS＋57 SKIP，共2663项**：完整回归第2批为2605 PASS＋57 SKIP，最终同 Case 多入口修正的174项关联复验通过，其中只有1项是新增用例。因此不是最终补丁单轮完整全绿；各组有重叠，不相加。

| 层次 | 已有证据 | 说明 |
| --- | --- | --- |
| 工程源码与 Skill | 1343项公开源码检查通过、13处 Skill 引用有效、101个锁定规范文件核对通过 | 不是新提交的远端 CI，也不是真实模型验收 |
| Case 专项 | 18项 Case 依赖工程用例及3项原生组合复验 | 包括共享／专属失效、合法多入口、纠正、普通重绑定、恢复和清理；与回归有重叠 |
| 包内隔离 | 256文件工程候选与选定源码及隔离解压内容逐字节一致；隔离 CLI 和所选 RSI 交付入口可用 | 未将开发目录作为隐式依赖；原工程包不是新的正式 Release |
| 原生 LOCAL 小样本 | 3条本地命令、零模型，原报告取回2次及资源清理完成 | 采用工程授权，仅支持所测本机路径，不代替真实人类授权 |
| 开发检查材料 | T22开发校准12例；T23开发校准55个唯一场景按批次归并 | 与正式任务结果分列，不追加到2606，也不抵消SKIP；首次失败保留 |

57项 SKIP 保持原身份与原因：47项原生 opt-in（35项接收器、11项 Codex 沙箱、1项离线沙箱），8项历史兼容本地 opt-in，2项 pytest 解释器 opt-in。新增原生或模型验证只支持各自覆盖的版本、环境与断言，不将这57项整体改为通过。
