# Harness Foundry v1.1.0

产品版本 **1.1.0**，协议保持 **2.9**。本版在 v1.0.0 之后已提交的参数诊断和 A0–A5 基础修补上形成固定发行；不纳入尚未提交的外接提供方实现，不改变原 R3 和既有验收分母。

## 新增能力

- **按需读取控制记录**：按同一 revision 获取控制视图，需要时补读来源正文；完整读取接口继续保留。
- **新库可选正文去重**：显式选择 `REVISION_BODIES_V1`，在同一 SQLite 数据库保存与复用来源正文；默认格式不变，既有库不自动迁移。
- **隔离副本转换与回滚准备**：开发源码中的 `devtools/migrate_revision_store.py` 比较事件、幂等返回、库外材料及原路径，保留旧库和增量；不切换活动库，不随通用运行 ZIP 交付。
- **基线与差异报告**：`tools/report_rsi_view.py query/read-source` 重建、查询和分页取回材料；可选 RSI 交付携带同版工具与指南。通用交接辅助脚本只关联材料和恢复收据。

## 修复项

- 使用稳定原因码说明未授权、撤销、过期、被替代及绑定错误，避免依赖错误措辞判断授权；原校验、累计预算与恢复语义保持不变。
- 公共 CLI 参数错误返回结构化 JSON 及非零退出码，帮助和正常调用保留兼容行为。
- 库外目录遍历失败显式标为待核对，保留其他已知文件、合法空目录和链接事实。
- 报告重建保留原条件、旧 FAIL/ERROR、未验依赖及缺失来源；视图或材料完整不自动成为接受状态。
- 版本声明、README、使用指南和相关测试常量统一为 1.1.0；旧版本记录不回改。

这些能力没有新增控制器或通用审批限制，也不重新派发已接受业务。详细入口见[基础修补](../FOUNDATION_REPAIRS.md)、[副本转换](../REVISION_STORAGE_MIGRATION.md)和[报告交接](../RSI_REPORT_HANDOFF.md)。

## 获取与使用

[v1.1.0 Release](https://github.com/alexYG-arch/Harness_Foundry/releases/tag/v1.1.0) 提供：

- `Harness-Foundry-1.1.0-generic.zip`：从明确选定的 Git 提交组装的通用运行包。
- `SHA256SUMS`：上述固定附件的 SHA-256。

在新目录解压，保留隐藏的 `.agents/`；使用声明的 Python 3.11+ 和项目工具，不复制旧 `.venv`：

```sh
python3 tools/hffactory.py version --json
python3 tools/hffactory.py --help
python3 tools/report_rsi_view.py --help
```

版本输出应为 `implementation_version: 1.1.0`、协议 `2.9`。运行 ZIP 只含通用运行依赖；可选能力包及开发维护工具从同标签源码按需选取，不隐式借用本机开发目录。

升级使用独立目录，核对实际加载位置和原控制记录。代码换版不自动升级部署、迁移数据库、恢复授权或撤销已发生的业务效果。历史生产入口保持退役。旧 v1.0.0 及更早标签、Release 和附件继续保留。

## 验证口径与边界

本版业务源码以 `f6ba5a4` 为基线，发行调整仅涉及产品版本、相关测试常量和说明。该基线的[公开源码 CI 为 1004/1004 通过](https://github.com/alexYG-arch/Harness_Foundry/actions/runs/40496841992)，零跳过。1.1.0发布源码另行通过1004项公开源码检查、Skill的9个引用及锁定规范校验；首轮有1项因测试子进程未继承源码路径而失败，按开发说明绑定路径后同版1004项全部通过，原失败记录保留，未改产品逻辑或断言。main/tag CI及同一固定ZIP的包内隔离、下载身份另行核对；最终提交、CI链接和附件摘要记录在Release。

原完整开发快照为 2379 PASS＋57 SKIP；补验按唯一身份归并为 **2436 项跨批次工程覆盖**，不是单轮全绿。该快照包含本版未提交的外接开发内容，不能把 2436 当作本版精简源码或 CI 的测试数量。历史 57 项 SKIP 及后续 57/57 补验分别保留版本、环境与断言；测试集合有重叠，不相加。

**收益仍未证实。** 真实旧库转换、路径搬迁和约 8.58GB 旧库缩减、实际部署采用、真实模型消费新报告及复杂 Coding 持续使用仍未验。历史本机原生结果不等于其他设备或生产服务通过。Coding 计划继续搁置；本次发布不操作活动库、不重放已接受模型任务，不消耗原业务预算。

源码和运行附件不包含本地执行数据库、私人运行证据或实际 Readback；工程验证不替代目标 Harness 的业务验收。
