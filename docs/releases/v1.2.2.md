# Harness Foundry v1.2.2

补丁版本 **1.2.2**，协议保持 **2.9**。纳入 `f08a1a0` 的预算与限时准备、目录诊断修复；没有新增调度器、审批层或业务流水线。旧标签、Release、附件和原失败证据保留。

## 修复内容

- `preview-build`、准备返回和 `read-build` 提供只读 `budget_planning`，分列完整 Plan 的首轮尝试、模型调用、独立检查和已声明预检。预算不足或没有返修余量仅作提示，不自动增额、不阻断有限执行；接续后不是剩余工作量或费用估算。
- 模型上下文提供 `command_time_budget`：一次模型调用的思考、内部工具和最终交接共用限时，并受授权剩余有效期截短。准备指南不再将样例的2/3次或900秒套为通用预算；原硬限时、授权校验和累计消耗不变。
- 准备与接收器共用指令候选解析，统一 override 覆盖顺序及链接实际目标。提前诊断缺失文件误填目录或在文件下创建写目录；保留合法父目录、目录别名、含点目录及被非空 override 遮蔽的同名目录。
- 增额和延时继续使用已有显式接续及真实批准；接受复用、只复验和完整报告取回不重放旧命令，不清零旧尝试，也不增加逐内部步骤确认。

参数见[固定版本CLI说明](https://github.com/alexYG-arch/Harness_Foundry/blob/v1.2.2/docs/GENERIC_BUILD_CLI.md#按任务准备次数和时间)，工程记录见[修复说明](https://github.com/alexYG-arch/Harness_Foundry/blob/v1.2.2/docs/BUILD_BUDGET_PREPARATION_REPAIR.md)。

## 下载与升级

从[本版Release](https://github.com/alexYG-arch/Harness_Foundry/releases/tag/v1.2.2)获取 `Harness-Foundry-1.2.2-generic.zip`、所需独立能力 ZIP 和 `SHA256SUMS`。运行包由本版明确提交构建；GitHub自动生成的源码 ZIP 不是运行交付包。

8个内置能力包不改版本和字节：qt-cmake@3、python-environment@2、data-summary@2、doc-export@2、host-review@2、local-dashboard@5、text-count@2、reference-notes@2。复用已发布附件并核对摘要，不包含具体第三方提供方实现。

在新目录解压，保留隐藏的 `.agents/`，使用已声明的 Python 3.11+：

```bash
python3 -I -S -B tools/hffactory.py version --json
```

预期产品版本1.2.2、协议2.9。明确切换实际运行入口；Git拉取、发布或解压本身不会替换旧部署、延长旧批准或增加额度。保留原Program、控制库、prepared、报告及累计消耗；未知效果先核对，完整捕获只取回。不迁移活动库，不复制不可迁移的虚拟环境。
