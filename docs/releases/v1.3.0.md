# Harness Foundry v1.3.0

版本 **1.3.0**，协议保持 **2.9**。包含v1.2.2之后的持续跟进、同Program追加产物声明，以及合同／样本校准、可选Case检查依赖和RSI新任务复用支持。保留旧标签、Release、附件、失败记录和累计预算；不新增控制器、审批层或通用限制。

## 新增能力

- 可选 `verification_resources.case_checker_files`：每个Case使用命令引用、全局文件及Case专属依赖的并集，由宿主绑定受保护副本。未使用该字段的项目保持原行为；接受仍按Workpack，不新增Case接受缓存。
- `examples/rsi-calibration`：可选择的合同校准知识材料，复用Wiki查询、理由记录和目标交付入口。条目仍为CANDIDATE；不强制查询、不自动采用或部署，不适用及空集合不阻断原任务。

## 修复与使用改进

- 外层Codex持续跟进同一CONTINUOUS运行，核实HELD交回原因并沿既有合法修复／接续入口推进。CONTINUOUS不是Chat订阅，不承诺聊天结束后自动通知。
- 同Program可在原任务写域内追加遗漏产物声明，保留原声明、真实批准、旧证据及累计消耗；新输出不借用旧PASS。生产上下文提供直接消费者的产物和依赖声明，帮助对齐共享入口。
- 合同与样本校准区分正常样本缺前提、故意无效输入、合法返回形态及真实副作用。规范blocker沿原协议交回；普通自然语言疑点供外层核实，不增加关键词停派。
- 准备、派发、纠正、重绑定及恢复使用一致的Case文件视图和签名；兼容同一Case多Workpack／多入口、共享依赖与合法路径。明确只有原同范围检查器纠正轮次免扣生产额度，其他历史及检查消耗保留。
- 交付清单补齐公开校准资料和依赖；完整报告按原绑定取回，不因清理或补日志重放模型、检查或业务命令。

具体入口见[固定版本CLI](https://github.com/alexYG-arch/Harness_Foundry/blob/v1.3.0/docs/GENERIC_BUILD_CLI.md)、[运行指南](https://github.com/alexYG-arch/Harness_Foundry/blob/v1.3.0/docs/GENERIC_BUILD_RUNTIME.md)、[合同校准](https://github.com/alexYG-arch/Harness_Foundry/blob/v1.3.0/docs/ACCEPTANCE_CONTRACT_ALIGNMENT.md)及[RSI示例](https://github.com/alexYG-arch/Harness_Foundry/blob/v1.3.0/examples/rsi-calibration/README.md)。

从[本版Release](https://github.com/alexYG-arch/Harness_Foundry/releases/tag/v1.3.0)获取 `Harness-Foundry-1.3.0-generic.zip`、所需独立能力ZIP和 `SHA256SUMS`。运行包由本版明确提交构建；GitHub自动生成的源码ZIP不是运行交付包。

8个内置能力包版本与字节保持：qt-cmake@3、python-environment@2、data-summary@2、doc-export@2、host-review@2、local-dashboard@5、text-count@2、reference-notes@2。复用适用旧证据及已发布附件并核对摘要，不包含具体第三方提供方实现。

在新目录解压，保留隐藏的 `.agents/`，使用已声明的Python 3.11+：

```bash
python3 -I -S -B tools/hffactory.py version --json
```

预期产品版本1.3.0、协议2.9。已有进程安全交回后再明确切换运行入口，核对当前工具、来源与实际部署版本。省略Case映射继续使用旧模式；切换新映射须完成适用复验，不能回写旧接受。发布不替换旧部署、不延长批准、不增加额度，不迁移活动库或复制不可迁移的虚拟环境。
