# Harness Foundry v1.2.1

补丁版本 **1.2.1**，协议保持 **2.9**。本版在v1.2.0之上纳入7660c97的累计预算增额修复，更新版本与交付说明；不新增调度器、审批层或业务流水线。旧标签、Release和附件保持不变。

## 修复内容

此前同Program接续只能保持原预算上限，用户已批准“已耗6次，再加1次”仍会被拒绝。本版通过现有准备和批准入口表达准确增量：

- `prepare-build-authorization` 同时声明 `rebind_from`、`budget_extension` 和新的绝对上限。准备仍为 `APPROVAL_REQUIRED`，不授予权限。
- 在完整Readback后沿用真实人类批准入口。原Plan、来源、读写域、有效期、撤销及未决效果继续核对。
- 已耗6次、上限从6改为7后，累计仍为6、剩1；第7次计入同一链，不退款、不清零。
- 总尝试与各任务统一上限分别核对；后者不是指定任务的专属额度。重复请求与普通后续接续不重复加额。
- 保留符合条件的接受复用、只复验身份、完整报告取回和原恢复路径，不因增额重放已完成命令。

参数与边界见[固定版本CLI说明](https://github.com/alexYG-arch/Harness_Foundry/blob/v1.2.1/docs/GENERIC_BUILD_CLI.md#保留累计消耗的显式增额)和[修复说明](https://github.com/alexYG-arch/Harness_Foundry/blob/v1.2.1/docs/BUILD_BUDGET_EXTENSION_REPAIR.md)。

## 新增与保持范围

这是既有预算能力的补修，不是新业务能力。8个内置参考能力沿用1.2.0的版本和原字节：qt-cmake@3、python-environment@2、data-summary@2、doc-export@2、host-review@2、local-dashboard@5、text-count@2、reference-notes@2。不包含具体第三方提供方实现。

## 下载与升级

从[本版Release](https://github.com/alexYG-arch/Harness_Foundry/releases/tag/v1.2.1)获取 `Harness-Foundry-1.2.1-generic.zip`、所需独立能力ZIP和 `SHA256SUMS`。能力附件沿用1.2.0固定字节，运行ZIP从本版选定提交重新生成并独立核对；GitHub自动生成的源码ZIP不是该运行包。

在新目录解压并保留隐藏的 `.agents/`，使用已声明的Python 3.11+解释器执行：

```bash
python3 -I -S -B tools/hffactory.py version --json
```

预期产品版本1.2.1、协议2.9。明确切换实际运行入口；仅更新Git工作区不会替换旧运行ZIP或既有Harness。保留原Program、控制库、旧prepared、报告和累计消耗。实际增额另存新范围并沿原批准路径，不改写旧批准；未知效果先恢复核对。不迁移活动库，不复制不可迁移的虚拟环境。
