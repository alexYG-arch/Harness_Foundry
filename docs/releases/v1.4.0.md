# Harness Foundry v1.4.0

Foundry 1.4.0 新增按需外接能力。项目可以为搭建任务和交付后的 Harness 分别选材。产品协议为 2.9，外接配置的 `selection_version: 1` 只用于选择这套新行为。

## 连接与升级

- 通过 `connect --on-demand` 登记供选择的包。在新版配置中分别填写 `build` 与 `target`。显式空选时保留项目基底和另行选择的原生能力。沿用旧配置的项目继续读取原注册表，保留原有 Skill 列表和功能映射的优先级。
- `build` 指定哪些材料进入 Workpack。`target` 决定接收方拿到目录、所选方法、全部公共条目或明确绑定的原生操作。仅交目录时，目标可查看名称、描述和来源摘要；仅用于搭建的材料留在搭建侧。
- 外部适配包可以声明 Skill、流程、代理和它们引用的文件。准备、复用快照和交付按当前选择核对绑定。已选包的依赖索引发生变化时须重新绑定。升级按上一次准备结果报告文件、任务输入及受影响 Workpack 的变化。
- pstack 继续由外部适配包提供。接入范围为 61 个 Skill 和 22 个流程，项目按需选择。运行包提供通用登记与交付工具，八个既有能力包也可独立下载。配置示例见[本版连接指南](https://github.com/alexYG-arch/Harness_Foundry/blob/v1.4.0/examples/capability-adapters/CONNECTIONS.md)。

## 下载与核对

从[本版附件](https://github.com/alexYG-arch/Harness_Foundry/releases/tag/v1.4.0)下载 `Harness-Foundry-1.4.0-generic.zip` 和 `SHA256SUMS`。校验下载的 ZIP，完整解压到新目录，保留隐藏的 `.agents/`。在解压目录用 Python 3.11 或更高版本运行以下命令，预期产品版本为 `1.4.0`、协议为 `2.9`。

```bash
python3 -I -S -B tools/hffactory.py version --json
```

使用旧项目时先确认实际使用的 Foundry 入口。要采用新版选择规则，再显式填写两份选择列表。对接只识别旧协议的接收端，可用 `--consumer-protocol 0` 检查兼容性。
