# Harness Foundry v0.5.0 发行准备

产品版本 **0.5.0**，协议版本 **2.9**，MIT 许可。当前为未发布候选源码。

本轮把临时文件、SQLite、产品运行副本、本机服务、必要 HTTP(S) 和按需测试凭据
接入现有独立验收流程。运行 cwd 与写入范围分别声明；判定依赖来自受保护副本。
报告在宿主归档，恢复读取既有结果，成功后清理本条命令的资源。

外层 Codex 负责核实原检查之外的问题、合并相关历史并判断继续与停止。
Harness 提供 `request-build-repair` 和可选 `ONE_ATTEMPT`，继续管理授权、实际预算、
原生修复和独立验收。默认连续推进及旧无资源配置保持兼容。

- 资源配置与可复用示例：[resource-check](../../examples/resource-check/README.md)。

Python 3.11+；通用运行包只依赖标准库。实际运行使用用户已声明的 Codex、模型与项目工具。
升级采用独立目录，保留旧包、项目与数据，继续使用明确批准的运行范围。
