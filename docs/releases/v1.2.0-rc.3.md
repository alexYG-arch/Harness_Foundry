# Harness Foundry v1.2.0-rc.3

产品预发布版本 **1.2.0-rc.3**，协议 **2.9**。本版从 v1.1.0 加入通用能力连接、功能选择与交付机制，以及8个内置参考能力新版本；不包含任何具体第三方提供方适配器或原包。稳定版仍为 v1.1.0，历史标签、Release和附件保留。

## 新增能力

- 目录／ZIP连接、来源版本发现与所选材料加载；ALL全部选择和ON_DEMAND需求选择，功能、共享文件、工具及环境分别绑定。
- 通用原生工具适配器、非标准包声明转换及有边界的改写准备；显式接收提供方适配器，不自动安装、执行或授予权限。
- 公开交付清单、受保护依赖检查、接收端重新绑定与报告恢复；连续升级沿原G/C/N保留定制、冲突和旧证据。
- qt-cmake@3、python-environment@2、data-summary@2、doc-export@2、host-review@2、local-dashboard@5、text-count@2、reference-notes@2；旧版本保留。

## 修复项

- 按最终交付形态核对依赖，保留合法搭建期依赖和AS_IS/BRIDGED组合。
- 新功能选择隔离同一连接的旧Skill列表，不影响其他连接和旧入口。
- 第三方决定绑定相关来源并在交付前复查；无关专属文件变化与同字节迁移保留决定复用，不新增审批层。
- 新版本Python／Qt依赖观察兼容同一Mach-O文件的多架构标题，保留各架构依赖、按文件去重及未知输出拒错。
- 新看板的回环监听不再进行无关反向DNS查询；本机HTTP工程夹具同步按字面IP绑定，等待、HTTP、报告恢复、清理及不重放断言保留。旧能力版本未改。

## 获取与使用

[预发布附件](https://github.com/alexYG-arch/Harness_Foundry/releases/tag/v1.2.0-rc.3)提供 `Harness-Foundry-1.2.0-rc.3-generic.zip`、8份独立能力ZIP和 `SHA256SUMS`。通用运行包来自明确Git提交；能力包只含声明文件、检查资源及许可证，不含SDK或本机工具。

在新目录解压并保留隐藏的 `.agents/`，使用Python 3.11+，先执行 `python3 tools/hffactory.py version --json` 与 `--help`；期望产品版本1.2.0-rc.3、协议2.9。能力选择、连接和交付见[使用说明](../CAPABILITY_ADAPTERS.md)与[功能指南](../../examples/capability-adapters/FEATURES.md)。工具在目标环境重新绑定，不复制旧 `.venv`。源码、固定包和目标部署版本分别记录，更新不清零原预算或重放旧任务。
