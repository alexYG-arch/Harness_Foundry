# Harness Foundry v1.0.0

产品1.0.0，协议2.9，MIT许可。v1.0.0标签固定本次源码；旧分支历史、标签、Release和下载附件保留。

## 新增能力（相对v0.5.0）

- 内置Harness设计指南，贯通需求、工具、独立检查和交付后使用。
- 可选能力接入、版本升级、环境绑定、定制保留及合法接续；Qt/Python等环境适配保留各自声明和验证范围。
- Foundry与目标Harness的只读看板，累计工作、真实步骤、历史、画中画及全屏展示共用状态。
- 可选RSI：案例导入与归因、Reviewer、TDD红绿关联、Wiki查询与采用快照、目标交付及采用证据。

## 修复与兼容

- 运行授权上下文、默认模型及手动冻结、通用模型服务配置与凭据脱敏、逐命令绑定、重连与历史重判、只复验和授权降频。
- 历史自检提取为源码资源，保留原生成字节及判定；源码分发携带资源，通用运行包不引入退役编译器及历史规范。
- 测试夹具支持含空格解释器路径并保留venv身份；加强关键启动参数断言；修正dashboard版本示例、历史reference及JSONL读取异常诊断。
- 五处测试SQLite连接显式关闭，保留原事务提交/回滚及断言，不修改生产数据库逻辑。

## 下载与使用

在本Release下载 `Harness-Foundry-1.0.0-generic.zip` 和 `SHA256SUMS`，校验后解压，保留隐藏的 `.agents/`。
Python 3.11+，通用运行包只依赖标准库。先运行：

```bash
python3 tools/hffactory.py version --json
python3 tools/hffactory.py --help
```

通过包内Skill及指南搭建目标；模型、服务、依赖和权限按实际任务声明。可选能力包从v1.0.0源码标签的 `examples/capability-adapters/packages/` 单独选择，第三方SDK和账号凭据不随ZIP分发。
项目升级使用独立目录和明确版本，保留旧状态、证据及累计预算；下载新版本不等于旧项目已经升级。
