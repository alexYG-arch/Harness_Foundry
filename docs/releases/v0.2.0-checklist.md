## 待用户确认的一次发布范围

准备完成后展示最终提交。拟覆盖：

1. 只向正式仓库正常快进更新 main，不强推、不删分支、不修改历史；先重新核对远端祖先关系。
2. 启用并核验该仓库私密漏洞报告；不改分支保护、账号安全或其他设置。
3. 等待同一提交的必需源码 CI 真正通过；失败/skip/未运行则停，不继续发布。
4. 创建未存在的 v0.2.0 tag 和 Release Draft，上传指定原 ZIP 和一行 SHA256SUMS；
   不上传原始会话/数据库/私有输入，也不覆盖现有同名 tag 或附件。
5. 发布该版本，下载核对 H1 并运行只读 version/help，报告真实 URL 与结果。
