## 1. 当前实现与修复

沿用同一通用 Build 控制器、独立检查、预算和恢复机制，没有新增执行引擎、状态库、
Hash 链或逐任务人工批准。用户确认搭建文档及运行范围后，可在批准域内继续推进；
合同冲突、权限/预算边界和未知副作用仍须停止。

- Plan 1.1 支持验收前置、环境预检和文件效果契约；旧 1.0 保持兼容，未声明契约不算已验证。
- 当前 accepted 输入和相关失败历史交给生产任务；恢复复用原命令观测，不重做已完成实施。
- 生产任务可读同一固定计划的下游义务，避免基础测试额外禁止已批准的后续能力。
- 完整正常模型回合可用结构化 `foundry_blocker` 报告合同缺口，由现有控制器停止并给出
  owner、evidence 和最小返回路径。报告不等于独立证明，不允许模型自报验收通过。
- `failure_kind` 明确为失败分类，`reason` 为说明。声明的错误、跳过、零用例不能包装成
  普通业务断言触发自动返修，也不能算完整通过；普通 exit 0 检查没有新增 JSON 必填要求。
- Task/CSV 准备模板只展开当前案例，保留共同约束；合法 scratch 可位于批准域内的
  `app/scratch` 或外部只读观察 workdir。不扩大读写域，不新增测试执行器。

接口细节见 [运行说明](GENERIC_BUILD_RUNTIME.md)、[搭建文档要求](GENERIC_BUILD_PLAN.md)。

## 2. 原对照评测：收益不是全局提升

升级前 A 为 `a580ae3d1b2982e15ee2c2690670e00acd59f047`，升级后 C 为
`903c14d6bec9e3efeaa4f7c533c167ea5ca6bf8b`。Ledger、Config 每任务每版本各三次，
使用等价业务计划和固定独立检查器；两版各 6/6 业务通过，每 Program 均三次模型会话。
下表先取各组三次中位数，再计算相对变化；不是挑最好一次，也不是最新修补的单独对照。

| 指标 | 升级前 A | 升级后 C | 样本内变化 |
| --- | ---: | ---: | ---: |
| Ledger 活跃耗时（秒） | 480.50 | 389.20 | −19.0% |
| Ledger 输入 / 输出 token | 526,176 / 15,406 | 413,957 / 13,128 | −21.3% / −14.8% |
| Config 活跃耗时（秒） | 399.55 | 394.93 | −1.2% |
| Config 输入 / 输出 token | 473,418 / 12,980 | 480,692 / 11,839 | +1.5% / −8.8% |

Ledger 达到预先约定的 10% 耗时改善门槛，Config 未达到；两版会话数没有减少。
每组仅三次，服务波动与缓存条件未被隔离，不能称统计显著、普遍更快或稳定性已提升。
B/D 文档澄清对照未运行，不能量化代码和文档各自贡献。G5E 使用兼容 Plan 1.0，
也不能单独证明每项 Plan 1.1 新字段的收益。

原评测还包括 Task 和 CSV 实用样本，合计 **13/14（92.9%）**；CSV 通过，Task 在
stats 复用时与生成基础测试冲突而阻断。原控制器在明确语义冲突后仍按缺产物重派，
属于已定位的 Foundry 缺口，不能全部归咎于搭建文档。该失败及其消耗仍保留在原分母。
原统一授权后无额外逐 Workpack 用户批准，但有两项非计划宿主干预和一次预定恢复操作，
不描述为“全程无人干预”。

最后两个样本均为零控制器重派；最终 25 组基础行为、7 组 stats 行为及九项项目测试
通过，基础测试和三个 Harness 文件字节保持不变。新会话确实读取并调用同一 Harness，
不是只检查产物存在或模型自述。

最新样本支持“修补后这个 Task 能正常建设、开发、复用和恢复”。它比前一通过样本
耗时增加约 3.7%，会话数不变；不能把修补说成再次提速，也不能因复测通过删除原失败。
预定恢复只覆盖 IMPLEMENT 原生命令已完整观测、尚待晋升的窗口，未重复派发该实施；
不证明任意崩溃恢复。最新样本的业务返修与合同缺口停止均未触发，记 `NOT_TRIGGERED`。

**范围保留：** 最新 HARNESS 模型自行做了空项目和缺参数负向接口冒烟，与 v1.1
“不额外异常注入”的严格口径有偏差。原始记录保留，不补算为正式故障分支验收；
没有新增宿主 Case、独立检查项或动态攻防，不宣称全过程零偏差。

取消型号限制后，最新三次请求仍选择 `gpt-6.1-sol`；实际服务返回型号/权重修订未知，
不是跨模型效果证明。原评测加三组修补样本累计 **51/76 次会话、7150.67/28800 秒**
活跃运行（约 1 小时 59 分），包含失败和取消的消耗。历史一个取消会话缺 usage，
费用未知，不能宣称金额节省。所有评测已结束，剩余预算不表示继续运行授权。
