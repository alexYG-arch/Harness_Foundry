# PRD＋设计任务：邻里预约

所有访谈、约束和页面参考均为合成材料。使用选定版本工作流、`inputs/brief.md`、`inputs/interviews.md`、`inputs/user-customization.json`，生成 PRD、需求/状态对应表和可实际查看的文件原型。首版展示 375px 手机与 1280px 桌面宽度；用 HTML/SVG，不要求实现真实后端或原生 Figma。

原型需要能操作选择场次、填写联系人、提交、查看容量不足/失败提示及重试；可由明确标记的演示状态切换器呈现服务响应，但不能把该演示称为已接入生产 API。覆盖空列表、无网络、提交中、网络失败、容量冲突、成功及返回后数据保留。附原型使用说明，把尚待业务决定的冲突说清楚。

交付实际生成的 `prd.md`、`traceability.json`、`prototype.html` 和 `design-notes.md`。流程、原型和解释都回到原输入；参考布局不是不可改变的答案。后续在真实浏览器运行并记录尺寸/状态/交互结果，文本存在不等于视觉或交互正确。
