# 数据推理：V1 → V2

升级的是分析工作流：在 V1 已正确处理缺失/单位/时区的基础上，V2 增加按渠道的分母核对及用户已声明参数下的敏感性区间。原始数据不换，目标日、时区、用户标签与情景上限保持；不是把换数据当成升级。

先用交付 V1 读取输入、运行计算并解释，再按普通文件机制升级实际加载的工作流为 V2；重新运行旧指标与新增分析，比较实际明细、公式及解释。预先手算的 expected.json 独立于生成脚本。数值全部相同也可能推断越界，需检查“完整营收”“增长”“因果”“观测上限”等具体说法。

固定材料测试只证明样例与手算相符；尚不证明交付 Harness 实际执行了计算、正确解释或完成了升级。当前两版业务均未运行。
