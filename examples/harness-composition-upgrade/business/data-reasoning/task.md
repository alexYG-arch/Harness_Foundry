# 数据计算推理任务：一天的预约收入

输入是合成的订单事件 CSV 和口径 JSON，不是真实财务台账。按 `metric-definition.json` 处理重复、修订、时区、状态、单位和缺失，产出可复算明细、指标 JSON 和面向业务的解释。

报告目标日的有效已付款预约数、已知金额小计、金额覆盖率及已知金额订单的平均金额。说明是否能确定完整收入、平均值或增长；不要把未知值当 0，也不要编造因果解释。V2 工作流还需要按既有用户参数给出条件情景范围和分组核对。这里不要求图表。

结果文件为 `normalized-orders.csv`、`metrics.json`、`analysis.md`，V2 另含 `sensitivity.json`。实际业务运行由交付的工作流读取输入、计算并解释；手算答案仅供独立验证，不是可直接返回的模板。
