# 数据工作流 V2：分母核对和条件情景

本版可独立加载：读取原 CSV、指标口径和用户参数，按 ID 取最高版本并去除相同重复行，转换时区后筛选目标日 paid，统一分/元，保留缺失为未知。使用声明的实际计算工具，输出明细、已付款数量、已知金额小计/覆盖率/均值，写明公式、分母、过滤及只在最终显示舍入；完整收入未知、没有对比期时不编造增长。保留用户时区、标签及金额口径，提交实际执行记录与成果供独立复算。相比 V1 增加：

1. 按 channel 展示有效订单数、已知金额数及小计，并把分组汇总与总指标核对；每个比例写出分母，缺失金额仍未知。
2. 如果用户明确提供 sensitivity_missing_amount_cap_yuan，计算“每笔未知金额介于 0 与该值”的条件总额/全体均值范围，标签必须写明情景假设；不能称真实营收已补齐或概率区间。保留无条件未知结论。

新增 sensitivity.json；同一批原始数据重算旧指标和新范围。规则升级不更改用户时区、标签、单位或情景参数，不要求改变输入文件。

## S3 文件与独立检查交接

读取共同的 [普通文件交接约定](../../OUTPUT_CONTRACTS.md)，按本版声明产出文件及结构；原始需求、口径和用户定制保持。独立预期只供受保护检查器，不读取它来填写答案。自动检查只关闭明确的文件/数值义务，不能替代实际业务执行、语义或视觉判断。

完成本次成果后由独立宿主按交接约定固定成果字节及真实执行记录，再完成对应的真实工具观察和审阅；受保护的后续 LOCAL 检查消费这些材料。当前 CODEX 子任务不继承宿主浏览器或搜索工具，ONE_ATTEMPT 也不在实施与验证之间暂停。未运行的工具/状态保留 NOT_RUN；不由生成方自填 PASS，不新增逐项用户批准。

实际计算沿声明的 Python/数据程序执行，保存调用和结果供独立宿主读回。受保护检查器另从原 CSV 复算明细、指标和本版范围；分析文字的分母、未知、因果和假设由独立宿主按原数据判定。
