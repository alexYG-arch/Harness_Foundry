# 市场调研：后续新问题工作流

从项目本次问题出发，明确要作的决策、适用时间/地区/版本、已有材料及未决事实。复用项目的业务口径与用户定制；不把旧问题的结论、固定来源数量或来源清单作为新问题答案。原始资料、来源陈述、计算、推断与未知分别写清。

需要公开检索时，交给 task.host_tools 声明的实际宿主。当前外层可选接口为 `web__run` 的 `search_query` 与 `open`；它不因此自动成为 CODEX 子任务工具。宿主用本次真实查询查找并打开相关原文，保存实际查询、工具返回、URL、可见发布日期/更新日期、检索时间、简短支持片段和适用条件。旧摘要或自填 tool ID 不证明已检索，来源页面缺少日期就保留未知。

由工作流实际消费本次取得的来源，给重要结论提供可定位的支持材料。独立审阅检查片段是否支持结论、版本与时间是否对应，计算分母是否可比；保留冲突的双方证据和未知，不凭来源名气或较新日期消除实质冲突。不同人群、时间、意愿和实际使用指标不可不加解释地合成增长结论。无需泛化到当前任务以外的市场或技术栈。

搜索、原文及语义观察完成后，宿主固定 task 声明成果和实际证据。独立 expectation 按本项目问题规定必需观察；check_review.py 只核对字节与已提供观察，不自行联网、重新搜索、认证来源真伪或批准业务。若发现真实结论错误，把原证据和失败理由交回原生产者按既有职责修复；缺证先补证，不重复派发固定成果复制器。

后续新问题、合法升级或受检成果变化时，沿项目任务继续调用实际工具并对相关结果重新判断。旧原文与旧失败保留，不将恢复原报告当成新检索，也不为取回结果重放已完成搜索。完成范围按真实行为解释：工程交接测试、固定材料分析和当次公开资料检索各有自己的证据，不能互相代替。
