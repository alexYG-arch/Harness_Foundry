# 最小作者模板

本目录是待填清单，不是可执行包。复制到新的 `packages/<name>/<version>/`，填写名称、操作和支持范围，补齐清单内的普通文件后才可prepare。不要直接把模板记为环境验证通过。

- `guide.md`：输入、输出、发现/绑定、实际调用、重新绑定、失败及报告取回方式。
- `environment.py`：纯绑定与显式执行分开；调用使用独立工具角色和明确profile；不自动安装、扩权或重试。
- `stack_runtime.py`：从同版本公共源复制；供公开入口和保护checker加载各自相邻同字节副本。相关新增公共helper也显式列入runtime/verification清单。
- `check_operation.py`：独立判定及保护加载；预期由项目单独提供，不能从产品输出生成。共享公开输入与私有预期分开。

按公共STACK_ENVIRONMENT格式生成profile；保持包版本、材料版本和工具版本独立。独立测试实际子进程、相关错误、受限接收器、清理/取回、显式升级与交付后新输入。只记录实际范围；fixture不替代目标Harness使用。

现成可运行参考分别是 `qt-cmake@2` 与 `python-environment@1` 的源码候选，不要求同时选择。项目位置、业务规则及本机环境保存在包外；沿完整选版升级和原文件合并保留定制，不创建新的注册器、预算或恢复系统。
