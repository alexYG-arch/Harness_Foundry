## 从选包到目标交付

1. 按 [README](README.md) 显式选择所需包和版本、项目 `.venv` 及环境绑定。`consume.prepare_call` 在宿主交出命令前核对选定文件与实际入口，但不执行。PRD／MARKET 的实际浏览器和搜索由当前宿主提供，包名、工具说明或文件存在均不能证明这些接口已可调用。
2. 将本项目后续使用需要的公开工作流、脚本和运行文件，连同项目自己的输入接口、配置、工具调用说明交付到目标。只使用 DOC 的目标无需携带研究规则；只做研究也不默认加载 PRD 规则。正式构建的来源按原需求选择，不每次重新扫描目录或强制重建 Harness。
3. 工具包目录不是目标工作区，`prepare` 也不是部署器。复制交付时显式列文件，保存实际生成基线 G、当前 C 和候选 N；修改或升级继续沿 [UPGRADE](UPGRADE.md)。直接引用外置工具时记录确切版本与路径，不复制开发机 `.venv`、SDK、完整私有材料或旧控制库。新环境重解析所需绑定。
4. 独立检查器、项目独立预期和宿主审阅快照留在宿主保护域。它们通过现有 `preparation.verifier_inputs` 与 `checker_files` 交接到 `verification_root`，实际运行从 `FOUNDRY_VERIFIER_ROOT` 内读取。公开原始 task／workflow／input 若同时供生产与检查使用，按现有 `shared:true` 声明；不能把独立预期标为 shared。宿主材料不交给生产者。

交付件从新的 cwd 使用公开脚本和声明解释器，不依赖 Foundry 数据库或搭建聊天的隐藏脚本。交付代码通过工程测试只是可调用性的局部证据；真实目标 Harness 的新会话／新材料使用仍按 V4/V6/V7 取得证据。

## PRD／MARKET 的普通宿主交接

[host-review 包说明](packages/host-review/1/guide.md)定义 `task.json` 的明确任务、工作流、输入文件、成果列表及实际宿主工具说明。该普通 JSON 不进入 Generic 协议。必查观察项由项目另存的独立 expectation 提供，不由生产者自填的 review 反推，也不从旧业务样例复制固定编号。

生成者先沿原流程交出成果；需要实际浏览器／搜索的部分由声明宿主在已有授权内完成并保存真实操作、截图或查询／原文记录。独立审阅者据原需求判断结果、给出理由和证据。`snapshot.py` 只固定本次任务、工作流、全部声明输入、成果及指定证据的原字节；它不调用这些工具、不制造 PASS、不认证审阅者身份，也不创建 Program 或接受记录。

`check_review.py` 核对受保护的项目任务与独立观察义务、本次受审字节和当前成果、观察记录及证据是否完整。缺证、UNKNOWN、NOT_RUN、版本不匹配均为 ERROR；实际有依据的业务 FAIL 为 ASSERTION。通过仅说明字节与已提供的独立观察符合要求，不意味着机器读懂了截图或证实了自由文字、URL／tool_ref 的真实性；这些仍依赖实际宿主调用和独立判断。

DOC 检查另在声明 scratch 内运行交付的实际 CLI 并对照项目完整独立预期，只容忍空白行差异。产品问题与设施故障的分类、具体命令和报告参数见 DOC guide。PRD／MARKET 的 review 检查不会为补日志而重新生成、浏览或检索。

## 复验、返修与恢复

已有 automatic／宿主审阅／reviewed 职责继续沿 [S3 宿主流程](../harness-composition-upgrade/integration/HOST_WORKFLOW.md)。`ONE_ATTEMPT` 在整次尝试后交回；它不是生成与检查之间的暂停点。reviewed 固定复制器不能修业务成果，真实缺陷仍回原生产者及原授权／预算；修后只补受影响的实际观察，固定新快照，旧失败和消耗保留。普通快照与检查输出不另建预算账目。

检查资源可使用已有 `STRUCTURED_V1`、`report_files:["summary.json"]` 与所选 `required_checks`。需要成功清理后仍取回的额外附件，按项目合同写入 report-staging 并显式声明；原始宿主证据放在独立保护域，不能只留在将被清理的 scratch。准备时完整列出 task 引用文件、快照所有文件及检查依赖，不能只列 snapshot.json 后假定它的间接引用会自动复制。

完整报告已捕获时，沿原恢复入口归档取回；不重放原 command、重新搜索或创建第二份计数。新输入、新工作流、新成果和新问题需新的适用证据；读取旧快照并不授权产生新结果，也不允许复用旧截图或旧搜索来冒充新使用。
